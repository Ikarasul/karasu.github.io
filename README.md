**ArtistHub** is a web application project for **ICT12267 (Web Application Development)**, Sripatum University.
🎯 **Core Objective:** To practice **AI-Assisted Development**, utilizing AI tools as a co-pilot to enhance coding efficiency, creativity, and UI design.

**เป้าหมายหลัก:** โปรเจกต์นี้จัดทำขึ้นเพื่อฝึกฝนทักษะการใช้ **AI เป็นเครื่องมือช่วยพัฒนา (AI-Assisted Development)** โดยเรียนรู้ที่จะทำงานร่วมกับปัญญาประดิษฐ์เพื่อเพิ่มประสิทธิภาพในการเขียนโค้ดและสร้างสรรค์ผลงานเว็บไซต์

---

### 🚀 Key Features (ฟีเจอร์เด่น)

* 🤖 **AI-Powered Workflow:** Developed using AI tools for smarter coding & debugging.
    * *พัฒนาโดยใช้ AI ช่วยเขียนโค้ดและแก้ปัญหา*
* ✨ **Interactive UI:** Glassmorphism design with 3D particle animations.
    * *ดีไซน์ทันสมัยแบบ Glassmorphism พร้อมพื้นหลัง 3D*
* 🐱 **AI Guru (MeowGuru):** Chat with an AI character for music recommendations (powered by Gemini API).
    * *ระบบแชทกับน้องแมว AI เพื่อขอเพลงแนะนำ*
* 🌍 **Global Radio:** Tune in to music stations worldwide via a 3D Interactive Globe.
    * *ฟังวิทยุจากทั่วโลกผ่านลูกโลก 3D*
* 🌗 **Dynamic Theme:** Full support for Light and Dark modes.
    * *รองรับทั้งโหมดสว่างและโหมดมืด*
